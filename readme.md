# Проект домашнего табло

Прочел как-то в интернете заметку про доброго человека, который сделал дома табло с актуальным расписанием времени до прихода автобуса (как на остановках в Москве). Идея понравилась и я ее благополучно забыл. А потом вспомнил.

Данный проект представляет собой домашнее табло (экран), которое показвает: 
а) погоду в определенной точке, описываемой координатами в формате WGS84. Используется API Яндекс Погода
б) расписание автобусов на 3х остановках по выбору (интересующие остановки описаны прямо в коде). Используется API Московский Транспорт

Итак, необходимо:
1. Сервер (мне кажется, подойдет Raspberry 3 и мощнее), лишь бы работал Python
2. Монитор (куплен на Авито за 300р в соседнем доме)
3. ПО

Собственно, ПО в файле main.py.

Особенности:
1. Написано роботом с небольшими доработками (Geminy, бесплатный режим)
2. Размер экрана 1280х1080
3. Python 3.12 (кажется 3.12, в общем тот, что по умолчанию в Ubuntu 24). Думаю, это не принципиально, лишь бы был пакет customtkinter
4. Чувствительные данные (APIKey Яндекс Погода, координаты) необходимо добавить в отдельный файл mysecretkeys.py в формате 

        YAweather_key = "XXXX-XXXX-XXXX-XXXX-...."

        YAlat = 50.XXXXX

        YAlon = 30.XXXXX
        
5. Приниципы работы с API Московский Транспорт я взял вот тут [https://github.com/egmen/moscow_transport](https://github.com/egmen/moscow_transport). Оно недокументируемое, гарантий никаких нет. И да, работает только в Москве. Кроме того, унылый гений набранных по объявлению программистов, которые пишут Московский Транспорт, тоже доставляет: например, видно, что информация о том, что в Москве есть остановки, на которых автобус останавливается в обоих направлениях по маршруту, стала для них неприятным сюрпризом
6. Зеленые данные о времени - это там, где поле telemetry = 1. Предполагаю, что это гласит о том, что есть данные непосредственно с автобуса, а не только из расписания. Но гарантии нет, возможно, это мои иллюзии в надежде на лучшее
